# 04 列头随时可拖换位

Status: done

## 问题

组间拖拽换序已实现但藏在编辑模式里,用户不知道,感觉「无法调换顺序」(反馈 #1;
诊断:编辑模式内拖拽实际可用)。

## 方案

- `GroupHeader` 的 draggable 门槛由 `editMode` 改为**随时**(view 态)。
- 列头悬停出 grab 光标 + 轻微抓取把手提示(列头 hover 时 grip 图标淡入,仅装饰)。
- 收藏卡片拖拽(组内排序/跨组移动)仍限编辑模式(与链接点击/原生链接拖拽冲突)。
- 放置逻辑不变(分区承接组间换位)。

## 验收

- 不开编辑模式即可拖组换位;编辑模式内行为不变。
- EditMode 测试更新 + 新增不开编辑模式的换位测试;`npm test`、typecheck 过。
