# 初曦(start-page)

一个 Chromium (MV3) 浏览器扩展:**初曦** —— 把新标签页覆盖为「初始页」,收藏按分组分区展示、搜索直达、数据可导入导出。仅支持 Chrome/Edge。

术语见 [GLOSSARY.md](GLOSSARY.md);架构决策见 [docs/adr/](docs/adr/)。

## 常用命令

环境要求:Node ≥ 22.22.2(建议 24 LTS)。

```bash
npm install        # 安装依赖
npm run dev        # Vite 开发模式(@crxjs HMR)
npm test           # vitest,单次运行全部测试
npm run typecheck  # tsc --noEmit
npm run build      # 构建可加载的扩展产物到 dist/
```

## 安装

### 方式一:下载现成构建(推荐)

1. 到 [Releases](https://github.com/smy-101/start-page/releases) 下载最新的 `start-page-v*.zip` 并解压
2. 打开 `chrome://extensions`,右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」,选择解压出的目录
4. 打开新标签页 → 显示「初曦」即安装成功。首次安装 Chrome 可能弹「改回 Google?」,选择「保持现状」保留新标签页覆盖

> 想要未发版的最新 main 分支构建:到 [Actions](https://github.com/smy-101/start-page/actions) 最近一次 `build` 运行页底部 Artifacts 下载(需登录 GitHub)。

### 方式二:自行构建(加载 dist)

1. `npm install && npm run build`
2. 打开 `chrome://extensions`,右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」,选择本仓库的 **`dist/`** 目录
4. 打开新标签页 → 显示「初曦」即安装成功(同上,选「保持现状」)
5. 代码更新后重新 `npm run build`,再到 `chrome://extensions` 点扩展卡片上的刷新按钮

注意:Chrome 品牌版 137+ 已禁用 `--load-extension` 启动参数,加载一律走 chrome://extensions 页面。
`npm run dev` 模式下产物指向本机 dev server,需保持 vite 进程运行,首次加载方式同上。

界面中文;深浅色跟随系统(CSS 变量 + `prefers-color-scheme`)。数据仅存本地 `chrome.storage.local`。

## 功能使用

### 收藏:三个入口

- **初始页「+」弹窗**:搜索框旁点「+」,弹窗内「添加收藏」页签填「网址 / 标题 / 备注 / 所属分组」,缺省进收集箱;网址自动规范化(缺协议补 https、去尾斜杠),标题留空自动取主机名。同一弹窗可切「新建分组」页签
- **工具栏一键收藏**:在任意网页点扩展图标,当前页连同页面标题一键进收集箱。图标两态 + 徽标:灰色瓷砖描边 = 未收藏,描边 + 右下角绿底 ✓ 徽标(类 AdGuard)= 已收藏(再点即取消),浅灰瓷砖 = chrome:// 等无法收藏的页面(点击无效果);收藏/取消后在当前页弹底部浮动条提示(activeTab 临时授权;不可注入页回退徽标文字一闪)
- **右键菜单**:页面空白处右键 →「初曦 → 收藏到 → 选择分组」直接入组;已收藏时菜单变「取消收藏」;对已收藏页面再「收藏到」其他分组即换组

### 白板看板与分组管理

- **白板看板**:分组卡在固定宽画布(基准 1200px)上自由摆放,哪几组摆在一起由你决定;窗口更窄时画布横向滚动不重排;条目多的列在列内滚动;网址与备注悬停可见
- **白板模式**(唯一编辑入口):头部「进入白板」。开启后拖动分组卡任意摆放(松手吸附 16px 网格)、收藏行出编辑 / 删除并可拖拽(组内排序 / 跨组移动)、分组列头出改名 / 换色 / 删除;点「完成」回到干净的浏览态
- **日常态锁拖**:不进白板模式拖不动分组;按住分组拖一下会出现引导提示,一键进入
- **自动整理**:白板模式内一键把全部分组重新贪心装箱,消除错落空隙
- **分组折叠**:列头箭头可折叠分组(默认全部展开,折叠状态记住;搜索时自动全部展开)
- 新建分组:自动落在画布底部第一个空位;「+」弹窗切「新建分组」页签(名字 + 色点)
- 删除分组:组内收藏自动移入收集箱、不会丢失,删除前有确认提示
- **全新安装引导**:空收藏状态下页面中央提供「从浏览器书签导入」一键初始化(也可手动添加)

### 搜索

搜索胶囊左侧点引擎名(默认必应)可直接切换 Google / 必应 / 百度,选中即保存、回车即用所选引擎搜索。输入即过滤:标题与网址全文匹配,无匹配内容的分组自动隐藏,全部无匹配时显示空状态。

### 网页图标

添加收藏时(「+」弹窗、工具栏一键收藏、右键菜单)由扩展直接请求网页解析 `<link rel=icon>` 并把图标存入本地,离线可用;首次使用会请求一次「读取网站数据」授权,拒绝后自动关闭(设置页可重新打开)。未抓到的图标回退浏览器 favicon 缓存与首字母方块。

### 设置(右上角齿轮)

- **网页图标**:添加收藏时自动抓取网页图标的开关(见上)
- **从浏览器书签导入**:一键把浏览器书签并入初始页——顶层文件夹转为分组、书签栏散项进收集箱、重复网址自动跳过,完成后给出「新增 N 条、跳过 M 条」统计
- **导出 JSON**:完整无损备份,分组颜色与顺序、收藏备注逐字保留;配合「替换全部」导入可整库迁移
- **导出 HTML**:Netscape 书签格式,可供 Chrome 等浏览器的原生书签管理器导入
- **导入文件**:JSON 可选「合并(跳过重复)」或「替换全部」;HTML 书签文件始终按合并导入

## 目录结构

```
manifest.config.ts            # MV3 manifest(defineManifest)
src/domain/                   # 领域层:纯 TypeScript,零 chrome.* 依赖,存储适配器注入
src/storage/                  # 存储适配器:chrome.storage.local 真实实现 + 内存实现(测试)
src/newtab/                   # 新标签页「初始页」React 应用
src/background/               # MV3 service worker:工具栏一键收藏接线(index.ts 汇聚入口)
tests/fixtures/               # 测试样本(真实形态的浏览器书签导出 HTML 等)
icons/                        # 扩展图标(PNG,manifest 仅支持位图)
public/icons/                 # 仅运行时 setIcon 引用的工具栏状态图标,Vite 原样复制进 dist
scripts/generate-icons.mjs    # 图标生成脚本:node scripts/generate-icons.mjs
```
