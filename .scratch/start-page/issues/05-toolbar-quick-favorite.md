# 05: 工具栏一键收藏 + 图标状态

**What to build:** 工具栏扩展图标成为一键收藏入口与状态指示:点击图标收藏当前页进收集箱,已收藏页再点一次即取消收藏;图标按当前标签页是否已收藏切换两套状态(未收藏=空心,已收藏=实心勾),切换标签页或页面导航时即时刷新(单标签页粒度,互不串扰);收藏/取消有瞬时视觉反馈。chrome:// 等无法收藏的特殊页面图标呈不可收藏状态。事件驱动由 service worker 完成,收藏判定走领域层。

**Blocked by:** 02(收藏核心:领域层 + 初始页增删改)

**Status:** ready-for-agent

- [ ] 未收藏页点图标:收藏进收集箱,图标变为已收藏态
- [ ] 已收藏页点图标:取消收藏,图标变为未收藏态
- [ ] 切换标签页、页面导航后,图标状态即时且正确(每个标签页独立)
- [ ] 操作有瞬时反馈(badge / title 提示)
- [ ] chrome:// 等特殊页面呈不可收藏状态,点击不产生数据
- [ ] 收藏/取消走领域层既有判重与不变量,测试通过
- [ ] 所需权限(tabs 读取 URL、图标资源)在 manifest 中声明齐全
