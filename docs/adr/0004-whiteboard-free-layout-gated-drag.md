# 分组看板改白板自由定位,拖拽锁进白板模式(取代 ADR-0003 瀑布流墙)

用户提案「排版在白板上进行,平常不允许拖曳,必须进白板模式」。grilling 一轮定五项口径(自由粒度/门禁发现性/坐标自适应/重叠空隙/原型先行),三变体 UI 原型(`prototype/board-whiteboard` 分支,preview harness `?variant=`)对比后 **2026-10-29 判定 B:白板+门禁**。

## Considered Options

- **A · 维持顺序墙(现状)**:自适应强、零迁移,但布局自由度低——用户要"哪几组摆在一起"的主控权。
- **B · 白板+门禁(选定)**:分组卡 x/y 坐标自由定位;拖拽唯一入口是「白板模式」;日常态锁死,拖动意图出 nudge 引导。
- **C · 白板免门禁**:自由最大,但误拖风险回到编辑模式门禁要解决的初衷;原型手感对比后弃。
- **自由编辑有序渲染**(拖拽仅定相对格局,渲染仍自适应重排):省自适应的坑但"自由"是假的;弃。

## Consequences

- **范式**:坐标即布局。分组存 x/y(schema V2→V3),存量 order 布局用 planWall 装箱一次性迁移;`order` 保留作 DOM/Tab 序(可访问性)。
- **门禁**:白板模式=原「编辑模式」升级改名(GLOSSARY 已更新);board-refresh/04 的"组头常时可拖"回退进门禁,发现性以**常驻入口 + 拖动意图 nudge**补偿(04 的教训:静默的锁会被当成"不能拖")。
- **画布**:固定 1200px,窗口更窄横向滚动,不重排;新分组自动落第一个空位。
- **吸附与兜底**:松手吸附 16px 网格;允许重叠;「自动整理」复用 planWall——ADR-0003 的装箱算法从布局引擎**降级为整理算法**,墙的测高/RO 壳退役。
- **拖拽实现**:Pointer 事件(跟手),画布层拦 `dragstart` 杀组头原生 DnD(否则劫持 pointermove);组内收藏排序仍走 HTML5 DnD 体系(DropHint 等)。
- 原型为一手资料:`git checkout prototype/board-whiteboard`,`preview/index.html?variant=B` 可复跑;实现工单 `.scratch/board-whiteboard/`。

**补记 2026-10-30(board-whiteboard/04)**:墙退役落地——白板成为唯一看板视图,
墙壳(BookmarkGroups 测高/RO)与组间换位原生 DnD 删除;本篇「复用 planWall」
所指装箱算法现名 `packCanvas`,与坐标几何同落 `src/domain/canvas.ts`。

**补记 2026-11-04(canvas-bounds-align)**:「固定 1200px」退役——用户看不见画布
边缘,右拖在无形的墙上弹回。画布宽改为**入库可调**(schema v3→v4,
`BookmarkState.canvasWidth`,默认 1200,钳回 [720, 2400],16px 吸附),白板模式
画布描边+点阵可见、右缘拖柄调宽;卡宽仍为全局常量不随画布拉伸,装箱列数随宽
自适应(`columnsFor`);拖拽中实时钳在画布内(不再先逃逸后弹回),并增加对象
对齐吸附与辅助线(阈值 8px,对象吸附优先于网格吸附)。详 `.scratch/canvas-bounds-align/`。

**补记 2026-11-04(canvas-bounds-align/04,自动档)**:「默认 1200px」再退役——宽屏上画布
只占屏心一条,两侧大片空白(用户反馈)。缺省改为**自动档**(schema v4→v5):
`canvasWidth` 缺省 = 撑满可用宽(组件实测滚动壳内容宽,`effectiveCanvasWidth`,
钳 [720, 2400]);拖柄调宽后钉住为固定宽入库。v4 曾给全部存量回填默认 1200,
与「用户调过」无法区分——v5 迁移把恰等于 1200 的按回填剥离回自动档(刻意
调回 1200 的会被误剥,重拖一次拖柄即恢复)。领域侧钳界自动档按上限
(`canvasBoundWidth`;实际渲染宽由组件先行钳过,钉窄时 `setCanvasWidth` 统一重钳)。
页面容器同步放宽(上限 = 画布上限 + 两侧衬距)。

**补记 2026-12(group-width-tint)**:「卡宽全局常量」退役——分组卡宽改由
**每行条数**推导(schema v5→v6,`Group.columns`,缺省 1 = 原 CARD_W 宽行单列,
观感逐字不变):c≥2 时组宽 = 38 + c×184 + (c−1)×6(首版 26 口径漏滚动槽 12,preview 实测修正;与 CSS `minmax(184px, 1fr)`
同源),组内收藏从纵向列表改横条自动换行网格。白板模式内每组右缘拖柄调宽
(松手吸附列边界、键盘步进一列),组头编辑表单可选每行条数;收集箱不可
改名/换色但可调宽。画布互钳:列数上界随画布宽(`maxColumnsForCanvas`),
缩画布时超宽组自动降列、落点按各组宽重钳;装箱(packCanvas)改宽度感知
(宽组占连续槽、窗口内最高槽最小,单槽组与旧行为逐字一致)。同时 3px 色脊
退役:组色改由托盘淡染(约 8%,自定义背景下半透明磨砂)+ 组头色点承担。
详 `.scratch/group-width-tint/`。

**补记 2026-12(group-span-decouple)**:上条补记「组宽由每行条数推导」退役——
组宽与每行条数解耦为两个旋钮(`Group.span` 组宽档位,schema v6→v7,零改写
迁移),表单改每行条数不再缩组宽,拖窄时每行条数自动跟降。详见 ADR-0005。

**补记 2026-12(ui-polish,组色表达收敛)**:「组头色点」退役——用户反馈
组头视觉过重(折叠钮+色点+名字+计数)。组色改由托盘底染+边框独立承担,
底染自约 8% 提至约 16%(换色前后差异可感,底色进 160ms 过渡),边框自
18% 提至 30%;折叠钮同步静音化(箭头 14→12px,静息墨色降至 55% 透明,
悬停/聚焦恢复)。色板自 8 色扩至 12 色(补暖橙/湖蓝/桃粉/靛蓝四个色环缺口),
存量分组色不受影响。
配套两项全局调校:圆角分级 r-lg 14→16px(组托盘/对话框/设置分区等
大面统一柔角),图标钮静息底改透明(托盘淡染上不浮白片,悬停才显)。
