# 02: 收藏核心:领域层 + 初始页增删改

**What to build:** 收藏与分组的全部业务逻辑落地为纯 TypeScript「领域层」(存储适配器注入,领域层不 import 任何 chrome.*),并接通初始页:能在初始页向收集箱添加收藏(URL/标题/备注),编辑、删除,点击卡片在新标签页打开网页;favicon 经 `_favicon` 端点显示,取不到回退首字母色块。URL 规范化判重(协议/主机小写、去 fragment、去默认端口、根路径去尾斜杠)只有一处实现,手动添加与后续导入共用。数据为单一状态对象,含 schemaVersion,持久化到 chrome.storage.local(经适配器,测试用内存适配器)。

**Blocked by:** 01(扩展骨架 + 初始页空壳)

**Status:** ready-for-agent

- [ ] 领域层提供:添加/编辑/删除收藏、建组、读取完整状态;经注入的存储适配器持久化,领域层代码零 chrome.* 依赖
- [ ] 两个存储适配器:chrome.storage.local 真实实现 + 内存实现(供测试)
- [ ] URL 规范化判重:重复 URL 添加被拒,初始页有用户提示
- [ ] 不变量测试(锁定):每个收藏必属且仅属一个现存分组;收集箱(id 固定 inbox)永远存在
- [ ] 初始页:添加收藏(URL/标题/备注)→ 出现在收集箱;点击卡片打开网页
- [ ] 初始页:编辑(标题/URL/备注)与删除收藏可用
- [ ] favicon 显示成功;加载失败回退为首字母色块
- [ ] 状态含 schemaVersion 字段
- [ ] 中文界面、深浅色跟随系统
