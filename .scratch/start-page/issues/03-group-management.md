# 03: 分组管理

**What to build:** 初始页上的全套分组管理:新建分组(名字 + 颜色)、重命名、换色、组间拖拽排序、组内拖拽排序、跨组移动收藏、折叠/展开;删除分组时其收藏自动回到收集箱,绝不连带删除;收集箱为保留分组,不可删除、不可改名换色。

**Blocked by:** 02(收藏核心:领域层 + 初始页增删改)

**Status:** ready-for-agent

- [ ] 新建分组(名字 + 颜色)后可将收藏添加/移动到该组
- [ ] 重命名、换色即时生效
- [ ] 拖拽三件套可用:组间排序、组内排序、跨组移动
- [ ] 折叠/展开可用,刷新后状态保持
- [ ] 删除分组:组内收藏全部回到收集箱(领域层测试锁定此行为)
- [ ] 收集箱不可删除、不可改名换色(UI 不提供入口,领域层拒绝)
- [ ] 领域层新增操作的测试与既有不变量测试全部通过
- [ ] 中文界面、深浅色跟随系统
