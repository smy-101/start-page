# board-refresh:看板布局重构 + 图标抓取

来源:用户一轮 7 条反馈(2026-10-29 会话),经澄清后的决策记录。

## 背景

ui-refresh/04 落地的看板是「1120px 页宽 + 固定 264px 横向列」。宽屏下两侧大片留白、
下方空间闲置;组间拖拽藏在编辑模式里不易发现;界面文本字形图标(⚙ ＋ 编辑/删除)观感一般;
`_favicon` 端点只覆盖访问过的站点,手动添加/导入的收藏大量回退首字母方块;
设置页已有「从浏览器书签导入」但新用户不知道。

## 决策(已与用户确认)

1. **组间拖拽**:列头**随时可拖**(不再限于编辑模式);收藏卡片拖拽仍留在编辑模式
   (避免与点开链接冲突)。
2. **布局**:页面放宽接近全屏,分组改**自适应网格**(auto-fill,约 300px 起),自动换行;
   列内条目多时列内滚动(上限高度)。两侧空间利用起来。
3. **分组样式**:随网格重做列卡视觉(列头层级、色点、计数、悬停)。
4. **折叠**:分组列头加折叠钮,**默认展开**,折叠态仅显示列头;折叠集 localStorage 持久化。
5. **网页图标**:添加收藏时由扩展**自己抓取**网页、解析 `<link rel=icon>` 存为 data URL
   (schema v2 新增可选 `icon` 字段)。用 `optional_host_permissions: <all_urls>`,
   首次添加时从提交手势请求一次;拒绝则静默回退 `_favicon`/首字母,不再骚扰。
   不用第三方图标服务(隐私 + 国内网络不可用)。
6. **导入入口**:全新安装态(仅收集箱、零收藏)在初始页中央给「从浏览器书签导入」CTA;
   设置页入口保留。

## 边界

- 原生书签导入**不**批量抓图标(一次几百站点不现实);导入项沿用 `_favicon`/首字母回退。
- 图标抓取入口覆盖:初始页「+」弹窗、工具栏一键收藏、右键菜单(service worker 共用同一模块)。
- 折叠是纯 UI 状态(localStorage),不进导出 JSON。
