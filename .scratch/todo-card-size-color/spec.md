# todo-card-size-color:待办卡调宽、每卡选色、添加行打磨

用户提案:「期望可以修改 todo 卡片大小,背景颜色,并优化 todo 卡片样式」。
grilling 一轮三问定案(2026-11-13):三项独立决定如下。

## 决定 1:自由宽(调大小)

- 待办卡退役「定宽 CARD_W」,改为**自由宽**:无档位、连续拖调,
  钳 **[240, 768] px**(均 16 倍数;缺省 = CARD_W,存量渲染逐字不变)。
  - 下限 240:紧凑卡(勾选框 + 约 12 字/行)——档位制以 CARD_W 389 为底,
    对紧凑清单偏宽(用户反馈);
  - 上限 768 ≈ 两倍缺省宽:宽过两倍缺省即不像卡。
- 交互与分组同语言:白板模式卡右缘拖柄**连续预览**,松手吸附**16px 网格**
  (同画布宽口径,非档位);键盘 ←/→ 步进一格网格;上限随画布宽收窄
  (自动档按上限 2400 的 768 封顶)。
- 联动:拖拽钳右界、自动整理装箱(packCanvas 宽度感知已在)按各自实测宽;
  缩画布宽至放不下时宽收窄到画布宽、坐标重钳(同分组口径)。
- **演进记录**:初版为档位制(6 档 +190 步距 → 调校 5 档 +95),
  经用户反馈(最大过宽、最小过宽、不想要档位)定案自由宽;schema v10
  迁移把 v9 档位按旧数学换算为 px(v9 未发布,仅本地开发版数据走换算)。
- 联动:拖拽钳右界、自动整理装箱(packCanvas 宽度感知已在)按各自档位宽;
  缩画布宽时超档待办降档、坐标按新宽重钳(同分组口径)。

## 决定 2:每卡自选色(背景颜色)

- **推翻 ADR-0006「v1 不做待办卡自选色」**:该决定记录于 ADR-0006 补记
  (见 issues/05)。缺省仍是**中性白卡**(color 缺省),选色才染色——
  「一眼区分待办与分组」的缺省观感不变,染色是用户主动行为。
- 每卡一色:白板模式卡头新增调色钮,展开卡内色板行(复用分组色板
  GROUP_COLOR_PALETTE/ColorSwatches)+ **「中性」复位钮**(清回缺省)。
- 表达:卡面底染(`--todo-color` 与 `--card` 混 ~12%)+ 边框微带色,
  自定义背景下与磨砂口径同形;**勾选框/指示线保持墨色**(色板含浅粉彩,
  白勾在浅底不可读;勾选是内容消费,墨色承担)。分组托盘底染 16%/待办
  卡面底染 12%:托盘沉、白卡浮的分层语言保持。
- 存储:`color?: string`(缺省 = 中性);空串 = 复位中性(recolorTodo
  空串语义,与分组「空色报错」分道);不做色值域校验(同分组:任意
  非空串收)。随 JSON 备份导入导出。

## 决定 3:添加行打磨(优化样式)

- 现状问题:卡尾常驻虚线框整日占据视觉重量,空卡上一框更吵。
- 方案:**幽灵行**——静息无框(transparent 边框占位保布局稳定),占位文本
  前加「+」语汇;悬停出与条目行同款的 4% 底色;聚焦出 45% 墨色实线框。
  语义与可达性不变(仍是常驻 input,回车即加)。

## 范围外(本票不做)

- 高度调节(列表 max-height 机制不动)、自由宽度(不吸附档位)、
  全局统一待办色、待办文本进搜索。
