# ui-refresh: 初始页交互重做(四项用户反馈)

2026-10-30 用户反馈四项,grilling 两轮定案(Round 1:图标三态 / 弹窗入口 / 编辑模式范围 / 看板布局;Round 2:折叠去留 / 引擎切换形态)。全部采用推荐方案。

## 决策

1. **工具栏图标三态重制**(生成脚本 `scripts/generate-icons.mjs` 重画):
   - 已收藏 = 靛蓝圆角方块 + 大号白勾(图标本体即勾,16px 可辨)
   - 未收藏 = 灰色书签描边(现状保留)
   - 不可收藏(含初始页自身)= 更浅的灰书签描边 + 现有 × 徽标,与未收藏拉开明度差
2. **添加收藏 / 新建分组移入弹窗**:页面只留搜索框、看板、设置齿轮;搜索框旁单个「+」按钮,弹窗内两页签切换。表单字段与校验不变。
3. **搜索引擎切换进搜索胶囊**:胶囊内左侧「引擎名 ▾」小按钮,点开下拉菜单,选中即持久化并全局生效;设置页引擎区块移除(设置页只剩原生书签导入 + 导入导出)。
4. **看板布局 + 全页编辑模式 + 彻底移除折叠**:
   - 分组 = 横向看板列(固定列宽,分组多时横向滚动);列头 = 色点 + 组名 + 计数
   - 收藏 = 列内长条行(favicon + 标题);URL 与备注进 `title` 提示,不占行宽
   - 头部「编辑」开关:开启后收藏行出现编辑/删除并可拖拽(组内排序/跨组移动),分组表头出现改名/换色/删除并可拖拽换位;正常状态完全干净
   - 折叠功能整体移除(按钮、collapsedGroups 持久化、首启折叠缺省、搜索强制展开逻辑全删);看板列常显
5. 搜索行为、领域层(store/search/url)、导入导出、右键菜单、工具栏点击收藏逻辑均不动。

## 性能注意(ADR-0002 交互)

移除折叠 = 首屏全量挂载,「懒挂载」措施失效;长条行 DOM 远轻于卡片,但 5000 条设计点需 perf-probe 复测首屏并记录进工单 04。若超预算 1.5 倍(>750ms),按 ADR-0002 升级条款提出新决策(不擅自加虚拟化)。
