# 02: 「+」按钮弹窗(添加收藏 / 新建分组)

**Type:** task
**Status:** done

## What

用户反馈:添加收藏/新建分组不想常驻界面。改为:

- 初始页移除两个内联表单(`AddBookmarkForm` / `NewGroupForm` 从页面布局中去掉)
- 搜索框旁单个「+」按钮 → 打开弹窗(dialog);弹窗内两个页签:「添加收藏」「新建分组」,默认「添加收藏」
- 表单字段、校验、错误提示与现状一致(就地中文提示);提交成功即关闭弹窗
- 可达性:Esc 关闭、点遮罩关闭、焦点进弹窗、`role="dialog"` + `aria-modal`

## DoD

- [ ] 页面无表单常驻;只有搜索胶囊、+ 按钮、看板、设置齿轮
- [ ] 弹窗两页签可切换;添加收藏成功后弹窗关闭、列表刷新
- [ ] 新建分组成功后弹窗关闭(新列展开出现——不再默认折叠)
- [ ] Esc / 遮罩点击关闭;表单错误就地展示不关弹窗
- [ ] 单测(App seam):打开/关闭/切换页签/成功关闭/失败留驻;`npm test` 全绿
