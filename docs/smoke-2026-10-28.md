## 发现与注意事项(均非产品缺陷,无需立票)

1. **CDP 安装的扩展不跨重启持久**:`Extensions.loadUnpacked` 属会话级安装,重启 Chrome 后需重载。仅影响自动化测试环境;真实用户经 chrome://extensions 安装无此问题。
2. **新标签页覆盖确认气泡**:安装后 Chrome 弹「改回 Google?此网页被扩展程序『初始页』更改了」,用户选「保持现状」后覆盖生效,选择随配置目录持久化。属 Chrome 标准扩展覆盖 UX。
3. **工具栏图标「固定到工具栏」未取得视觉证据**:前次运行通过扩展菜单行点击触发 action(功能已验证),但 pin 操作未成功落图;图标三态已有程序级铁证(`action.getTitle`/`getBadgeText` 与 setIcon 同一调用路径)。不构成缺陷。
4. **冒烟未覆盖项**:卡片上的编辑/删除按钮未在浏览器中逐个点验(领域层已有单测覆盖;删除收藏已经工具栏与右键两个入口验证)。10-rclick-menu.png 为误入 Edge 窗口的干扰帧,弃用;以 10b 起为准。
